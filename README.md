# Vehicle Parking System - Sprint 1 (Member 2 Module)
This module addresses the five core Sprint 1 requirements outlined in the SRS:
- **PVT-F-004**: Real-time slot availability grouped by zone.
- **PVT-F-005**: Filter slots by two-wheeler and four-wheeler.
- **PVT-F-015**: Admin UI to add, edit, and remove parking slots.
- **PVT-F-008**: Record vehicle entry and update slot status.
- **PVT-F-009**: Record vehicle exit and free the slot without fee processing.

## Setup Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python app.py`
3. Access the system at `http://127.0.0.1:5000`
